# Index of archived mathematical-error records

Each record has only an `original/` folder and a `witness.md` file. The witness identifies the original statement and its source location, explains the recorded defect, and links to the supporting materials.

This is a layout-only reorganization of `paper-and-data-77-20260922.zip`. All 77 archived records and all files previously under `materials/` are retained. Those source files are byte-for-byte unchanged; they include the previously extracted conversation windows and sanitized source copies, not newly recovered complete originals. The witness text and review status are inherited, not independently reverified. Record 058 remains marked as a false positive, and pending checks remain pending. Original source paths and relevant locations are retained in each witness; the earlier archive remains the reference for full machine-readable provenance. This is not a finalized positive-error release.

The witness contains the consolidated annotations; quoted source text is marked as a quotation. There are no separate per-record README, original-excerpt, reasoning-summary, event-list, metadata, or manifest files. Links created by this reorganization resolve within this archive; links inside unchanged source artifacts remain as originally recorded and may refer to external or historical paths.

Existing visible CoT summaries and reasoning excerpts remain in the unchanged files under `original/`. Where the supplied archive provides explicit reasoning anchors, the corresponding `witness.md` now links to their source events and records their locations and inherited alignment notes. No summaries have been generated or reconstructed, and no additional per-record files have been introduced.
