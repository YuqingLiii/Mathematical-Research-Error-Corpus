# Yoshida 一级分类：65 条错误记录

本版按用户选定的 Yoshida 等人一级框架重新逐条编码，替代自拟的五标签及二十标签版本。**65 条收录、错误原文与 witness 不变。** 不新增“证明缺口”或 overclaim 标签，不给记录赋二级类别。

参考：[Yoshida et al., Table 2 / §3.2](https://arxiv.org/html/2609.15145#S3)，arXiv:2609.15145v1，2026-09-23 核对。沿用其五个大类；研究问题中的构造、计算程序和任务交接按下述规则适配。不是声称逐字照搬全部二级定义，也不把分类体系本身作为新贡献。

本次只重审旧版 II 类的六条记录（008、019、031、032、036、055）。032、036、055 的原文保留具体错误推导或定理应用，改归 IV；其余三条保持 II。其余 59 条标签不变；65 条来源、witness 和收录决定全部不变。详见 [六条过程核对](CONCEPT_ORIGIN_AUDIT.md)。

## 如何区分

- I 问题理解：题目、任务、输入的既定条件被改变。证明内部漏掉某定理假设不自动算 I。
- II 数学知识：定理/概念内容本身被说错、不同概念被等同。不推断模型内部记忆状态。
- III 计算与代数：可见运算、数量估计或计数错误。未知是否抄错时，不凭错数的外观归 V。
- IV 逻辑推理：正确事实被错误使用、必要前提未满足、局部证据不支持整体断言、构造正确性/结构判断不成立。正常未完成的证明不自动算错。
- V 其他：本轮是 063、065 两条材料更新/转录错误，不是“无数学错误”。原论文的“正确/非错误”子项不进入本库。

## 与原框架的适配和边界

1. 我们的单位是错误记录，不是完整解答；原文、witness 和既有候选/已证状态共同约束标签。没有把被反驳候选自动说成证明已完成。
2. 一级类别下的构造/结构推断可用于研究型候选，不要求最终答案格式。027、038、044、057 的原候选身份保留；不据反例猜测隐藏思维。
3. I 的题目对象包括 agent 转写的后续任务（060）；V 扩展到代码数据更新和下一轮输入转录（063、065），而不只原论文的最终答案抄写。这些适配不是新错误类别。
4. 多标签必须分别写明依据。本轮 022 的不一致比较基准与错误零点是两个可分的局部缺陷；037 的任务可行域遗漏与随后普遍化声明分别记录。其余不因为最终论证失效而自动再加 IV。
5. 数学标签存在判断边界。逐条表明确说明 II/III、III/IV 等易混处的选择，不声称既有框架使分类变得天然互斥或无主观判断。
6. 这是基于冻结 source/witness 的逐条 AI 辅助分类，不是一次新的独立数学审稿，不宣称双人标注或所有原始大计算重新运行。

## 典型例子

- **060 → I**：下一轮任务漏掉原来的正间隙条件；接收方指出错误，不是接收方出错。
- **019 → II**：交换不变不等于只支撑于对称子空间。
- **018 → III**：非交换矩阵乘积的消去次序写反。
- **047 → IV**：正确算出 T_b/m 不代表已证明物理 T_b 的同一个界；不另贴“证明缺口”。
- **065 → V**：文本替换意外改变输入计数；不说它不是数学错误，也不把它当作接收方推理失败。
